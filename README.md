## 📚 Projeto de Estudo

Este projeto está sendo desenvolvido com o objetivo de estudo e prática de **animações em JavaScript** aplicadas a interfaces web.

A proposta é explorar diferentes formas de criar animações e entender como integrá-las de maneira estruturada dentro de um site, trabalhando também conceitos de organização de código e composição de layout.

⚠️ **Status do projeto:**  
O projeto ainda **não está finalizado** e continua em desenvolvimento conforme avanço nos estudos e testes de novas implementações.

### Objetivos do projeto
- Praticar animações utilizando **JavaScript**
- Testar formas de **estruturação e organização do código**
- Experimentar diferentes abordagens de **interatividade no front-end**
